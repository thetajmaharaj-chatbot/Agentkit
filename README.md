# AgentKit SA
Premium, offline-first Android toolkit for South African real-estate agents.

## UI milestone
The first milestone establishes the complete navigation map and visual language before data/backend work.

### Main areas
Home, Properties, Leads & CRM, Calendar, Marketing Studio, Documents, Seller Reports, Deal Pipeline, Commission, Expenses & Mileage, Agent Branding and Settings.

### Build
Open in Android Studio (JDK 17), sync Gradle, then run the `app` configuration.
